title: Using images and videos as script references
category: Studio
published: true
---
Upload images or reuse assets from your project as references. Type @ in the script
to link an image or video by name.

Numbered aliases such as @image_1 and @video_1 bind to a specific media item within
the project. Repeated uses of an alias refer to the same item. Renaming that item
does not break an existing reference binding.

Before starting generation, resolve any missing or ambiguous references. The app
blocks generation when it cannot identify the referenced media, before reserving
funds for the request.

The current video provider accepts one video reference per generation request.
Choose your references with that limit in mind.

Each generation keeps a snapshot of its script, resolved references and settings.
Changing references later does not replace an existing generated video or alter
the input snapshot of work already submitted.
